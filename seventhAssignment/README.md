# ProfileLab

A simple iOS profile screen built with Swift and Storyboard
The screen includes a profile picture, name, statistics, Follow and Message buttons, and an About section

## Tech Stack

- Xcode
- Swift
- UIKit
- Storyboard
- Auto Layout

## How to Run

1. Open `ProfileLab.xcodeproj` in Xcode
2. Select iPhone SE (3rd generation) or iPhone 16 Pro Max as the simulator
3. Press **Run** to build and launch the app
